# Transmutation Engine Classic

Offline Python + Streamlit version of the hallucinating logic engine.

**Features**
- Fully local (no Google, no API keys)
- Controllable entropy (chaos) and stabilization (truth-seeking)
- Strict autogram validator
- Easy to integrate with hyperlisp or HyperClaw

**Setup**
```bash
pip install -r requirements.txt
streamlit run app.py
